# Customized Cakes

Premium responsive customized-cake website built with React + Vite.

### Final design
- Strict **light blue + white** theme
- No pink/rose theme
- No cake prices
- Cake designs shown for inspiration
- WhatsApp enquiry/order flow
- Supplied Customized Cakes logo

### Run locally
```bash
npm install
npm run dev
```

### Build
```bash
npm run build
```

### GitHub Pages
Push the **develop** branch. The included GitHub Actions workflow automatically builds and deploys to GitHub Pages.

The supplied logo is included at `public/logo.png`.
